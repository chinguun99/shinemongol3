
# Shine Mongol 3 – Student Hub

A student community and educational entertainment website.

## Requirements
- Google Chrome, Edge, Firefox or Safari
- No installation required
- Internet connection for external educational websites

## Setup

1. Create a folder named shine-mongol-3.
2. Save index.html, style.css, app.js and README.md inside it.
3. Save the school logo image as logo.png in the same folder.
4. Open index.html in your browser.

## Features
- School announcements
- Student community
- Educational games for grades 1–12
- External educational games
- Study resources
- Responsive design

## Important
This is a frontend demo.

News and community posts are stored in browser localStorage.
They are not shared between different students or devices.

A real student login, shared chat, school announcements
and administrator dashboard require a backend and database.

This is an independent student project concept,
not an official school website.
